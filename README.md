# Animation Retargeter

**Transfer Animations Between Rigs in Unity**

Retarget animations from one character rig to another.

## Features

- **Auto Bone Detection** - Automatically maps bones between rigs
- **Scale Adjustment** - Handle different sized characters
- **Root Motion** - Preserve or remove root motion
- **Curve Remapping** - Intelligent animation curve transfer
- **Preview** - Test before committing
- **Validation** - Check setup before retargeting

## Installation

1. Import this package into your Unity project
2. Go to **Tools > Animation Retargeter**

## Usage

1. Assign source rig and animation clip
2. Assign target rig
3. Click "Auto-Detect Bone Mapping"
4. Click "RETARGET ANIMATION"

## Supported Rigs

- Mixamo characters
- Unity Humanoid rigs
- Custom bone hierarchies

## Requirements

- Unity 6.3 LTS or later
